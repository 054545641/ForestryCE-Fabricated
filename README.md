# Forestry CE - Refabricated

Forestry CE - Refabricated is an unofficial port of [Forestry: Community Edition (Forestry CE)](https://www.curseforge.com/minecraft/mc-mods/forestry-community-edition)
to newer Minecraft versions on Fabric. Forestry CE is a fork of the classic [Forestry](https://github.com/ForestryMC/ForestryMC)
Minecraft mod, known for its bees, trees, and automatic farms.

This port is maintained independently by **054545641**, who has no affiliation with either the Forestry CE team or the Forestry team.
It is developed solely under the terms of the upstream [open-source license](LICENSE.md).

### Maintenance and Archival Policy

- This project only provides updates for the latest Minecraft version with Fabric loader.
- Relevant bug fixes from upstream Forestry CE are incorporated periodically as part of the synchronization cycle.
- If either the Forestry team or the Forestry CE team releases an official Fabric version for the same Minecraft version,
  the corresponding version of this repo will no longer be updated.

### In-Game Manual on Fabric 26.2

Patchouli does not yet have a Fabric release for Minecraft 26.2, so the **Forester's Manual** is temporarily unavailable
in the current Fabric 26.2 version. This limitation does not affect the trade catalogue or other features that do not depend on Patchouli.

### Reporting Bugs
Please report bugs with ForestryCE-Refabricated in [this repository's issue tracker](https://github.com/054545641/ForestryCE-Fabricated/issues).
Before opening a report, please make sure the bug has not already been reported by [searching the issues](https://github.com/054545641/ForestryCE-Fabricated/issues?q=is%3Aissue).

For crashes, you must post a link to the full crash report.
[gist.github.com](https://gist.github.com) is a good place to upload them.
Full crash reports are located in [the minecraft data folder](http://hopper.minecraft.net/help/finding-minecraft-data-folder/), in "crash-reports".

Thank you for reporting bugs!

### Building

The `26.2-fabric` branch uses the root Loom build for Fabric 26.2, with Jade and JEI available for development.
Import the root Gradle project in your IDE.
On Windows, run `scripts/setup-fabric.ps1`, then `gradlew-fabric.bat runClient`.
With Java 25, `gradlew build` produces four independent JARs in `build/fabric-26.2/libs`.
See the [Fabric development guide](docs/fabric-development.zh-CN.md) for more details.

The version remains alpha: Patchouli/KubeJS/Rhino integration is temporarily closed, extra accessory slots are not ported,
and cross-version/cross-loader world upgrades are not certified.

The [NeoForge development guide](docs/local-development.zh-CN.md) applies only to the `26.2-neoforge` branch.
